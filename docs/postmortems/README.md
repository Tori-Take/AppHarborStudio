# AppHarborStudio ポストモーテム

Studio 固有の失敗・改善記録。

## このリポジトリで記録するもの

- カートリッジ生成プロンプトの不備
- Studio UX の問題
- PGlite モック実装の挙動と本番のズレ
- Stage 1〜5 ワークフローでの躓き

## このリポジトリで記録しないもの

| 種類 | 配置先 |
|---|---|
| SDK API / 型契約の問題 | [appharbor-sdk](https://github.com/Tori-Take/appharbor-sdk) の `postmortems/` |
| AppHarbor 本体の CI / インフラ | [appharbor](https://github.com/Tori-Take/appharbor) の `docs/ci-postmortems/` |
| 複数リポジトリ横断 | [appharbor-sdk](https://github.com/Tori-Take/appharbor-sdk) の `postmortems/` |

## ファイル命名規則

```
YYYY-MM-DD-短い説明.md
例: 2026-05-23-stage5-schema-diff-design.md
```
